<h2>① この回で扱う内容</h2>

<p>ワークブック第6章、連続型分布と標本分布です。1回では収まらないので、前編と後編に分けます。<br /><br />前編で扱うのは7つ。連続一様、正規、指数、ガンマ、ベータ、コーシー、対数正規です。<br />後編は2変量正規、混合正規、そしてカイ二乗・$${t}$$・$${F}$$。<br /><br />この章の記号は $${\chi^{2}}$$ ですが、出てくるのは後編です。<br />前編の主役は $${f(x)}$$。確率密度関数のことです。</p>

<p>この回を読み終えると、次の5つができるようになります。</p>

<p>$${f(x)}$$ の値が1を超えていても、慌てずに面積を見られること。<br />正規分布の式のどこが $${\mu}$$ でどこが $${\sigma}$$ か、指で押さえられること。<br />指数分布とガンマ分布を、待ち時間という1本の線でつなげられること。<br />ベータ分布を「割合そのものの分布」として読めること。<br />コーシー分布に平均がない理由を、裾の重さから説明できること。</p>

<p>第5章の最後に書いた「分布を見たら、まず $${x}$$ がどこから動くかを確認する」が、この回ではそのまま道具になります。</p>

<h2>② 事前に必要な知識</h2>

<p>3つ確認します。</p>

<p>1つめ、積分は面積です。<a href="https://note.com/toukei_igakusei/n/n42e050da1b5a">道具箱③</a>でやりました。</p>

<p>$$<br />\int_{a}^{b} f(x)\,dx = \text{曲線 } y=f(x) \text{ の下の、} a \text{ から } b \text{ までの面積}<br />$$</p>

<p>連続型分布の話は、最初から最後までこの1行に乗っています。<br />積分の計算そのものは、この章ではほとんど出てきません。面積だと思えれば足ります。</p>

<p>2つめ、$${e^{x}}$$ と $${\log}$$ です。<a href="https://note.com/toukei_igakusei/n/n1a3651daeb17">道具箱②</a>の範囲。<br /><br />$${e^{-x}}$$ は右下がりで、0に近づきますが0にはなりません。指数分布とガンマ分布の裾は、全部この形をしています。<br />微分の形も1つだけ使います。</p>

<p>$$<br />\left( e^{g(x)} \right)' = g'(x)\, e^{g(x)}<br />$$</p>

<p>3つめ、期待値と分散の定義です。<a href="https://note.com/toukei_igakusei/n/n0e8456180419">第3章</a>から、$${\sum}$$ が $${\int}$$ に変わるだけです。</p>

<p>$$<br />E[X] = \int_{-\infty}^{\infty} x f(x)\,dx, \qquad V[X] = E[X^{2}] - \left( E[X] \right)^{2}<br />$$</p>

<p>足す相手が飛び飛びの点から、つながった線になった。それだけの違いになります。<br />分散を $${E[X^{2}] - (E[X])^{2}}$$ で出す手順も、離散型のときと同じです。</p>

<p><a href="https://note.com/toukei_igakusei/n/n9c15ee8d3edc">第4章</a>の変数変換も、最後の対数正規分布で使います。そこで改めて書きます。</p>

<h2>③ 直観的なイメージ</h2>

<p>離散型の確率関数は、棒グラフでした。棒の高さがそのまま確率です。<br />$${f(4) = 0.25}$$ と書いてあれば、$${X}$$ が4になる確率が0.25。読み方に迷う余地がありません。<br /><br />連続型では、これが成り立ちません。</p>

<figure><img src="https://raw.githubusercontent.com/tomohiro19287-crypto/note-figures/main/ch06a_fig01_density_area.png" alt="" /><figcaption>離散型は棒の高さが確率。連続型は塗った面積が確率</figcaption></figure>

<p>身長がちょうど170.000...cmの人がいる確率はいくつか。<br />小数点以下が無限に続くので、答えは0です。値が連続だと、1点の確率は必ず0になります。<br /><br />棒がつぶれてしまうわけです。高さが0の棒をいくら並べても、確率にはなりません。<br /><br />そこで、高さではなく面積を確率にします。</p>

<p>$${f(x)}$$ は、その点の確率ではありません。その点のまわりの<strong>混み具合</strong>です。<br /><br />人口密度と同じ考え方になります。「1平方キロあたり5000人」は人数ではありません。面積をかけて初めて人数になる。<br />密度そのものは人数ではないので、値がいくら大きくても構いません。</p>

<p>だから、冒頭の話が起きます。<br />0から0.5の区間に確率1を詰め込むには、高さを2にするしかない。幅0.5×高さ2で、面積がちょうど1です。</p>

<figure><img src="https://raw.githubusercontent.com/tomohiro19287-crypto/note-figures/main/ch06a_fig02_uniform_height.png" alt="" /><figcaption>区間を狭めると密度は1を超える。それでも面積は1のまま</figcaption></figure>

<p>区間をもっと狭めれば、高さは10にも100にもなります。<br />それでも面積は1です。確率が1を超えたわけではありません。</p>

<h2>④ 解説と式変形</h2>

<h3>確率密度関数：守るルールは3つだけ</h3>

<p>連続型分布は、次の3つを満たす関数 $${f(x)}$$ で決まります。</p>

<p>$$<br />\text{(1)}\; f(x) \geq 0 \qquad \text{(2)}\; \int_{-\infty}^{\infty} f(x)\,dx = 1 \qquad \text{(3)}\; P(a \leq X \leq b) = \int_{a}^{b} f(x)\,dx<br />$$</p>

<p>(1)は密度が負にならないこと。(2)は全部の面積が1であること。(3)が確率の読み方です。<br />離散型の「$${f(x) \geq 0}$$」「$${\sum f(x) = 1}$$」と、まったく同じ3つになっています。</p>

<p>ここから、離散型では起きなかったことが1つ出てきます。</p>

<p>$$<br />P(X = a) = \int_{a}^{a} f(x)\,dx = 0<br />$$</p>

<p>幅0の面積は0です。1点の確率は必ず0になる。<br />つまり $${P(X \leq a)}$$ と $${P(X \lt a)}$$ が等しい。連続型では、等号を入れるかどうかを気にしなくてよくなります。<br /><br />離散型では大問題でした。$${P(X \leq 3)}$$ と $${P(X \lt 3)}$$ は $${f(3)}$$ だけ違う。ここが緩むのは、連続型の数少ない楽なところです。</p>

<p>累積分布関数も第2章のままです。</p>

<p>$$<br />F(x) = P(X \leq x) = \int_{-\infty}^{x} f(t)\,dt, \qquad F'(x) = f(x)<br />$$</p>

<p>密度を積み上げたものが $${F}$$、$${F}$$ を微分し直したものが密度。行き来は微分と積分だけです。</p>

<h3>連続一様分布：面積が1になるように高さを決める</h3>

<p>区間 $${[a, b]}$$ のどこも同じ混み具合、というのが連続一様分布 $${U(a,b)}$$ です。<br />$${f(x)}$$ は定数になります。値は、面積が1になるように決まります。</p>

<p>$$<br />f(x) = \frac{1}{b-a} \qquad (a \leq x \leq b)<br />$$</p>

<p>幅 $${b-a}$$、高さ $${1/(b-a)}$$。かけて1です。<br />$${U(0, 0.5)}$$ なら高さは $${1/0.5 = 2}$$。冒頭の2は、ここから出ていました。</p>

<p>期待値は定義どおりに積分します。</p>

<p>$$<br />E[X] = \int_{a}^{b} x \cdot \frac{1}{b-a}\,dx = \frac{1}{b-a} \left[ \frac{x^{2}}{2} \right]_{a}^{b} = \frac{b^{2}-a^{2}}{2(b-a)} = \frac{a+b}{2}<br />$$</p>

<p>最後は $${b^{2}-a^{2} = (b+a)(b-a)}$$ で約分しました。区間の真ん中です。<br />分散も同じ手順で $${E[X^{2}]}$$ を出します。</p>

<p>$$<br />E[X^{2}] = \frac{1}{b-a} \left[ \frac{x^{3}}{3} \right]_{a}^{b} = \frac{b^{3}-a^{3}}{3(b-a)} = \frac{a^{2}+ab+b^{2}}{3}<br />$$</p>

<p>$${b^{3}-a^{3} = (b-a)(a^{2}+ab+b^{2})}$$ を使いました。あとは引くだけです。</p>

<p>$$<br />V[X] = \frac{a^{2}+ab+b^{2}}{3} - \frac{(a+b)^{2}}{4} = \frac{4(a^{2}+ab+b^{2}) - 3(a+b)^{2}}{12} = \frac{(b-a)^{2}}{12}<br />$$</p>

<p>$${(b-a)^{2}/12}$$。第5章の離散一様分布が $${(n^{2}-1)/12}$$ でした。分母の12が共通しているのは偶然ではありません。同じ形の積分と和から出ています。</p>

<h3>正規分布：$${\mu}$$ と $${\sigma}$$ しか入っていない</h3>

<p>$${X \sim N(\mu, \sigma^{2})}$$ の密度です。この章でいちばん見た目が厳しい式になります。</p>

<p>$$<br />f(x) = \frac{1}{\sqrt{2\pi\sigma^{2}}} \exp\left( -\frac{(x-\mu)^{2}}{2\sigma^{2}} \right)<br />$$</p>

<p>丸暗記するものではありません。3つの部品に分けて読みます。<br /><br />いちばん奥の $${(x-\mu)^{2}}$$ が「中心からどれだけ離れたか」の2乗。<br />それを $${\sigma^{2}}$$ で割って「$${\sigma}$$ 何個ぶん離れたか」に直しています。<br />前についた $${1/\sqrt{2\pi\sigma^{2}}}$$ は、全体の面積を1にするための係数です。中身の形には関係しません。</p>

<p>$${\exp}$$ の中にマイナスがついているので、中心から離れるほど値が小さくなる。左右対称の山になります。</p>

<figure><img src="https://raw.githubusercontent.com/tomohiro19287-crypto/note-figures/main/ch06a_fig03_normal_params.png" alt="" /><figcaption>μ は山の位置、σ は山の幅。それしか動かせない</figcaption></figure>

<p>$${\mu}$$ を変えると、形はそのままで左右に動きます。<br />$${\sigma}$$ を変えると、位置はそのままで幅が変わる。幅が広がれば、面積を1に保つために高さが下がります。<br /><br />いじれる場所が2つしかない。正規分布が扱いやすいのは、この単純さのおかげです。</p>

<p>そして、$${\sigma}$$ を物差しにすると面積が固定されます。</p>

<figure><img src="https://raw.githubusercontent.com/tomohiro19287-crypto/note-figures/main/ch06a_fig04_68_95_997.png" alt="" /><figcaption>μ±σ で約68%、μ±2σ で約95%、μ±3σ で約99.7%</figcaption></figure>

<p>$${\mu}$$ や $${\sigma}$$ がいくつであっても、この割合は変わりません。<br />正確には $${\mu \pm 1.96\sigma}$$ でちょうど95%です。この1.96は、第9章の信頼区間まで何度も出てきます。</p>

<p>割合が $${\mu}$$ と $${\sigma}$$ によらないので、位置と幅をそろえてしまえば全部が同じ分布になります。標準化です。</p>

<p>$$<br />Z = \frac{X - \mu}{\sigma} \sim N(0, 1)<br />$$</p>

<p>$${\mu}$$ を引いて中心を0へ、$${\sigma}$$ で割って幅を1へ。これは第4章の変数変換そのもので、$${|dx/dz| = \sigma}$$ を掛ければ確かめられます。<br /><br />偏差値も同じ操作です。標準化してから、平均50・標準偏差10になるように置き直します。</p>

<p>$$<br />\text{偏差値} = 50 + 10 Z = 50 + 10 \cdot \frac{X - \mu}{\sigma} \sim N(50, 10^{2})<br />$$</p>

<p>偏差値70は $${Z = 2}$$、つまり上から約2.3%。偏差値が意味を持つのは、点数が正規分布に近いときだけです。</p>

<p>再生性もあります。独立な $${X \sim N(\mu_{1}, \sigma_{1}^{2})}$$ と $${Y \sim N(\mu_{2}, \sigma_{2}^{2})}$$ について</p>

<p>$$<br />X + Y \sim N(\mu_{1}+\mu_{2},\; \sigma_{1}^{2}+\sigma_{2}^{2})<br />$$</p>

<p>期待値も分散もそのまま足す。第3章の性質が、分布の名前ごと保たれます。<br />差をとるときは $${\sigma_{1}^{2}+\sigma_{2}^{2}}$$ のまま、引き算になりません。分散は引いても足されます。第11章の2標本の検定で、ここを踏み外すと答えが合わなくなります。</p>

<h3>指数分布：ポアソン分布の裏側</h3>

<p>第5章のポアソン分布は「一定期間に何回起きるか」を数えていました。<br />同じ現象を、時間の側から見ます。次に起きるまで、どれだけ待つか。</p>

<p>1時間に平均 $${\lambda}$$ 回起きるとき、待ち時間 $${X}$$ は指数分布 $${\mathrm{Exp}(\lambda)}$$ に従います。</p>

<p>$$<br />f(x) = \lambda e^{-\lambda x} \qquad (x \geq 0)<br />$$</p>

<p>導き方は、ポアソン分布からそのまま出ます。<br />時刻 $${x}$$ まで1回も起きない確率は、$${\mathrm{Po}(\lambda x)}$$ で0回になる確率です。</p>

<p>$$<br />P(X \gt x) = \frac{(\lambda x)^{0} e^{-\lambda x}}{0!} = e^{-\lambda x}<br />$$</p>

<p>これで累積分布関数が決まり、微分すれば密度になります。</p>

<p>$$<br />F(x) = 1 - e^{-\lambda x}, \qquad f(x) = F'(x) = \lambda e^{-\lambda x}<br />$$</p>

<p>期待値は積率母関数から出すのが速い。第2章でやった $${m(\theta) = E[e^{\theta X}]}$$ です。</p>

<p>$$<br />m(\theta) = \int_{0}^{\infty} e^{\theta x} \lambda e^{-\lambda x}\,dx = \lambda \int_{0}^{\infty} e^{-(\lambda-\theta)x}\,dx = \frac{\lambda}{\lambda - \theta} \qquad (\theta \lt \lambda)<br />$$</p>

<p>$${\theta \lt \lambda}$$ でないと積分が発散します。指数の肩が正になって、無限大に飛んでいくからです。<br />あとは微分して $${\theta = 0}$$ を代入するだけになります。</p>

<p>$$<br />m'(\theta) = \frac{\lambda}{(\lambda-\theta)^{2}}, \qquad m''(\theta) = \frac{2\lambda}{(\lambda-\theta)^{3}}<br />$$</p>

<p>$$<br />E[X] = m'(0) = \frac{1}{\lambda}, \qquad E[X^{2}] = m''(0) = \frac{2}{\lambda^{2}}, \qquad V[X] = \frac{2}{\lambda^{2}} - \frac{1}{\lambda^{2}} = \frac{1}{\lambda^{2}}<br />$$</p>

<p>1時間に2回起きるなら、平均の待ち時間は30分。$${E[X] = 1/\lambda}$$ は直観と合います。</p>

<figure><img src="https://raw.githubusercontent.com/tomohiro19287-crypto/note-figures/main/ch06a_fig05_exponential.png" alt="" /><figcaption>指数分布は x = 0 が最頻値。3分待っても、残り時間の分布は最初と同じ</figcaption></figure>

<p>グラフを見て意外に思ったのが、$${x=0}$$ がいちばん高いことでした。<br />平均が30分でも、いちばん起こりやすいのは「すぐ起きる」です。平均と最頻値が一致しない分布は、ここが最初になります。</p>

<p>指数分布には、幾何分布と同じ性質があります。無記憶性です。</p>

<p>$$<br />P(X \gt s+t \mid X \gt s) = \frac{e^{-\lambda(s+t)}}{e^{-\lambda s}} = e^{-\lambda t} = P(X \gt t)<br />$$</p>

<p>$${s}$$ だけ待ったあとでも、そこから先の待ち時間の分布は最初とまったく同じになります。<br />「もう10分待ったから、そろそろ来る」は成り立ちません。<br /><br />第5章の幾何分布と、式の形まで同じです。$${(1-p)^{k}}$$ が $${e^{-\lambda t}}$$ に置き換わっただけになっています。離散の待ち時間が幾何分布、連続の待ち時間が指数分布。同じ話の両側です。</p>

<h3>ガンマ分布：指数分布を $${a}$$ 回ぶん重ねる</h3>

<p>1回目まで待つのが指数分布なら、$${a}$$ 回目まで待つとどうなるか。ガンマ分布です。<br />ワークブックの記号では $${X \sim \mathrm{Ga}(a, b)}$$、$${a}$$ が形状母数、$${b}$$ が尺度母数になります。</p>

<p>$$<br />f(x) = \frac{1}{\Gamma(a)\, b^{a}}\, x^{a-1} e^{-x/b} \qquad (x \gt 0)<br />$$</p>

<p>$${\Gamma(a)}$$ はガンマ関数です。面積を1にするための係数で、次の積分で決まります。</p>

<p>$$<br />\Gamma(a) = \int_{0}^{\infty} t^{a-1} e^{-t}\,dt, \qquad \Gamma(a) = (a-1)\Gamma(a-1), \qquad \Gamma(1) = 1<br />$$</p>

<p>$${a}$$ が自然数なら $${\Gamma(a) = (a-1)!}$$ になります。階乗を、整数でない値まで伸ばしたものだと思えば足ります。</p>

<p>$$<br />E[X] = ab, \qquad V[X] = ab^{2}<br />$$</p>

<p>$${a=1}$$ を入れると $${\Gamma(1)=1}$$、$${x^{0}=1}$$ で、密度が $${e^{-x/b}/b}$$ になります。</p>

<p>$$<br />\mathrm{Ga}(1, b) = \mathrm{Exp}\left( \frac{1}{b} \right)<br />$$</p>

<p>指数分布はガンマ分布の $${a=1}$$ の場合でした。$${b}$$ は1回あたりの平均待ち時間で、$${a}$$ が「何回ぶん待つか」。$${E[X]=ab}$$ は、1回10分のことを3回待てば30分、と読めます。</p>

<figure><img src="https://raw.githubusercontent.com/tomohiro19287-crypto/note-figures/main/ch06a_fig06_gamma.png" alt="" /><figcaption>a が増えると山が右へ動き、形が正規分布に近づいていく</figcaption></figure>

<p>$${a}$$ が増えると、$${x=0}$$ に張りついていた山が持ち上がって右へ動きます。<br />$${a}$$ が大きいところでは、形が正規分布に似てきます。独立な待ち時間を $${a}$$ 個足しているので、第7章の中心極限定理がここに顔を出しています。</p>

<p>再生性もあります。$${b}$$ が同じなら</p>

<p>$$<br />\mathrm{Ga}(a_{1}, b) + \mathrm{Ga}(a_{2}, b) = \mathrm{Ga}(a_{1}+a_{2}, b)<br />$$</p>

<p>2回ぶん待って、そのあと3回ぶん待てば、5回ぶん。$${b}$$ がそろっていないと成り立ちません。1回あたりの平均が違う待ち行列は、足しても同じ形にならないからです。</p>

<p>ここで記号の流儀に注意が要ります。<br />ワークブックは $${b}$$ を尺度母数として $${e^{-x/b}}$$ と書き、$${E[X]=ab}$$ です。ところが $${b}$$ を率として $${e^{-bx}}$$ と書き、$${E[X]=a/b}$$ とする流儀も広く使われています。<br />見分け方は $${e}$$ の肩です。$${-x/b}$$ なら尺度、$${-bx}$$ なら率。$${E[X]}$$ が $${ab}$$ か $${a/b}$$ かを確かめれば確実になります。</p>

<h3>ベータ分布：割合そのものの分布</h3>

<p>ここまでの分布は、値が0以上か実数全体でした。ベータ分布は0から1しか取りません。</p>

<p>$$<br />f(x) = \frac{1}{B(a,b)}\, x^{a-1} (1-x)^{b-1} \qquad (0 \lt x \lt 1)<br />$$</p>

<p>$${B(a,b)}$$ はベータ関数で、これも面積を1にするための係数です。</p>

<p>$$<br />B(a,b) = \frac{\Gamma(a)\Gamma(b)}{\Gamma(a+b)}, \qquad E[X] = \frac{a}{a+b}, \qquad \text{最頻値} = \frac{a-1}{a+b-2}<br />$$</p>

<p>係数を外して見ると、$${x^{a-1}(1-x)^{b-1}}$$ です。第5章の二項分布 $${p^{x}(1-p)^{n-x}}$$ と、そっくりな形をしています。<br /><br />違うのは、どちらが変数かです。<br />二項分布は $${p}$$ を固定して、成功回数を動かしていました。ベータ分布は回数のほうを固定して、確率 $${x}$$ を動かします。<br /><br />つまり「$${a-1}$$ 回成功して $${b-1}$$ 回失敗するのを見たあとで、真の成功確率はどのあたりか」を表した分布になります。</p>

<figure><img src="https://raw.githubusercontent.com/tomohiro19287-crypto/note-figures/main/ch06a_fig07_beta.png" alt="" /><figcaption>a と b の大小で、山の位置と偏りが決まる</figcaption></figure>

<p>$${a}$$ が大きければ右寄り、$${b}$$ が大きければ左寄り。<br />$${a=b=1}$$ を入れると $${x^{0}(1-x)^{0}=1}$$ で、$${U(0,1)}$$ にぴたりと一致します。</p>

<p>$$<br />\mathrm{Be}(1,1) = U(0,1)<br />$$</p>

<p>何も情報がない状態を表す分布が、区間 $${[0,1]}$$ の一様分布になる。第31章のベイズ法で、ベータ分布が事前分布として使われる理由がここにあります。</p>

<h3>コーシー分布：平均が存在しない</h3>

<p>標準コーシー分布の密度です。</p>

<p>$$<br />f(x) = \frac{1}{\pi (1 + x^{2})} \qquad (-\infty \lt x \lt \infty)<br />$$</p>

<p>左右対称で、真ん中が0の山です。見た目は正規分布と大差ありません。<br />中身はかなり違います。独立な標準正規 $${Z_{1}, Z_{2}}$$ の比 $${Z_{1}/Z_{2}}$$ がこの分布で、自由度1の $${t}$$ 分布と同じものです。</p>

<figure><img src="https://raw.githubusercontent.com/tomohiro19287-crypto/note-figures/main/ch06a_fig08_cauchy_vs_normal.png" alt="" /><figcaption>中心付近は似ている。裾は桁が違う（右は縦軸が対数目盛）</figcaption></figure>

<p>右のグラフが本題です。縦軸を対数にすると、裾の減り方の差が見えます。<br />正規分布は $${e^{-x^{2}/2}}$$ で落ちるので、離れるほど猛烈に小さくなる。コーシー分布は $${1/x^{2}}$$ でしか落ちません。<br />$${x=6}$$ のあたりで、密度は100万倍以上ちがいます。</p>

<p>この裾の重さが、期待値を壊します。</p>

<p>$$<br />\int_{0}^{\infty} \frac{x}{\pi(1+x^{2})}\,dx = \frac{1}{2\pi} \Bigl[ \log(1+x^{2}) \Bigr]_{0}^{\infty} = \infty<br />$$</p>

<p>$${x}$$ をかけると、分子が $${x}$$、分母が $${x^{2}}$$ で、$${1/x}$$ の形が残ります。$${\log}$$ は発散する。<br />プラス側もマイナス側も発散するので、差し引きが定まりません。左右対称だから0だ、とはいかないわけです。</p>

<p>期待値がないので、分散もありません。<br />標本平均を取っても、$${n}$$ をいくら増やしてもばらつきが減らない。大数の法則が効かない分布として、第7章でもう一度出てきます。</p>

<h3>対数正規分布：$${\log}$$ をとると正規に戻る</h3>

<p>$${\log X}$$ が $${N(\mu, \sigma^{2})}$$ に従うとき、$${X}$$ は対数正規分布に従います。<br />密度は第4章の変数変換で出せます。$${y = \log x}$$ とおくと $${x = e^{y}}$$ なので</p>

<p>$$<br />\frac{dy}{dx} = \frac{1}{x}, \qquad f_{X}(x) = f_{Y}(\log x) \left| \frac{dy}{dx} \right| = \frac{1}{x\sqrt{2\pi\sigma^{2}}} \exp\left( -\frac{(\log x - \mu)^{2}}{2\sigma^{2}} \right)<br />$$</p>

<p>正規分布の $${x}$$ を $${\log x}$$ に置き換えて、前に $${1/x}$$ が付いただけです。この $${1/x}$$ がヤコビアンになります。<br />$${\log}$$ を取るので、$${x \gt 0}$$ でしか定義されません。</p>

<figure><img src="https://raw.githubusercontent.com/tomohiro19287-crypto/note-figures/main/ch06a_fig09_lognormal.png" alt="" /><figcaption>右に裾が伸びるので、最頻値・中央値・平均がこの順にずれる</figcaption></figure>

<p>右に長い裾ができるので、3つの代表値がずれます。</p>

<p>$$<br />\text{最頻値} = e^{\mu - \sigma^{2}}, \qquad \text{中央値} = e^{\mu}, \qquad E[X] = e^{\mu + \sigma^{2}/2}<br />$$</p>

<p>ここが罠でした。$${E[X]}$$ は $${e^{\mu}}$$ ではありません。$${\sigma^{2}/2}$$ が肩に乗ります。<br />$${\log}$$ を取った世界の平均が $${\mu}$$ でも、もとの世界に戻すときに $${\sigma^{2}/2}$$ だけ持ち上がる。ばらつきが大きいほど、平均は中央値から離れていきます。<br /><br />中央値のほうは素直に $${e^{\mu}}$$ です。順位は $${\log}$$ を取っても変わらないので、真ん中は真ん中のままになります。</p>

<h3>7つを1枚に並べる</h3>

<p>ここまでの分布を、値の動く範囲で分けます。</p>

<figure><img src="https://raw.githubusercontent.com/tomohiro19287-crypto/note-figures/main/ch06a_fig10_family_tree.png" alt="" /><figcaption>値の動く範囲で3つに分かれる。後編でここにカイ二乗・t・F が加わる</figcaption></figure>

<p>有限の区間しか取らないのが、一様分布とベータ分布。<br />0以上しか取らないのが、指数分布とガンマ分布。<br />実数全体を取るのが、正規分布とコーシー分布。対数正規分布は $${\log}$$ を取ったときに実数全体になります。<br /><br />問題文を読んで「時間」「回数」「金額」が出てきたら0以上、「割合」なら0から1、「誤差」なら実数全体。範囲を決めた時点で候補は2つに絞れます。</p>

<h2>⑤ オリジナル練習問題</h2>

<p>問1<br />0以上0.5以下の範囲に、等確率で点を打ちます。その位置を $${X}$$ とします。<br />(1) $${f(x)}$$ を求めてください。<br />(2) $${P(0.1 \leq X \leq 0.3)}$$ を求めてください。<br />(3) $${P(X = 0.2)}$$ を求めてください。<br />(4) $${E[X]}$$ と $${V[X]}$$ を求めてください。</p>

<p>問2<br />ある試験の点数が $${N(60, 15^{2})}$$ に従うとします。<br />(1) 75点以上を取る人の割合を求めてください。<br />(2) 上位10%に入るには何点必要ですか。$${z_{0.10} = 1.28}$$ とします。<br />(3) この試験で偏差値70は何点にあたりますか。<br />(4) 点数を偏差値に直す式を書いてください。</p>

<p>問3<br />あるコールセンターに、1時間あたり平均6件の電話がかかってきます。ポアソン過程とみなせるとします。<br />(1) 次の電話までの待ち時間 $${X}$$ の分布と、$${E[X]}$$、$${V[X]}$$ を求めてください。単位は分とします。<br />(2) これから10分間、1件もかかってこない確率を求めてください。<br />(3) すでに10分間、1件もかかってきていません。ここからさらに10分間かかってこない確率を求めてください。<br />(4) (2)を、ポアソン分布を使って別の方法で求めてください。</p>

<p>問4<br />(1) $${\mathrm{Ga}(3, 2)}$$ の $${E[X]}$$ と $${V[X]}$$ を求めてください。<br />(2) 問3のコールセンターで、3件目の電話までの待ち時間の分布と期待値を求めてください。<br />(3) $${\mathrm{Be}(3, 7)}$$ の期待値と最頻値を求めてください。<br />(4) 10人に薬を使い、2人に効きました。事前分布を $${\mathrm{Be}(1,1)}$$ とすると、事後分布は $${\mathrm{Be}(3, 9)}$$ になります。その期待値を求め、$${2/10}$$ と比べてください。</p>

<p>問5<br />(1) $${\log X \sim N(0, 1)}$$ のとき、$${X}$$ の中央値と期待値を求め、大小を比べてください。<br />(2) ある集団の年収が対数正規分布に従い、$${\log(\text{年収})}$$ の平均が $${\log 400}$$、標準偏差が $${0.5}$$ だとします。年収の中央値と平均を求めてください。単位は万円とします。<br />(3) 標準コーシー分布に期待値が存在しない理由を、積分の形で説明してください。</p>

<h3>解答</h3>

<p>問1<br />(1) 幅0.5に面積1を詰めるので、高さは2です。</p>

<p>$$<br />f(x) = \frac{1}{0.5 - 0} = 2 \qquad (0 \leq x \leq 0.5)<br />$$</p>

<p>(2) 幅 $${0.3-0.1=0.2}$$ に高さ2をかけます。</p>

<p>$$<br />P(0.1 \leq X \leq 0.3) = 0.2 \times 2 = 0.4<br />$$</p>

<p>(3) 0です。幅が0なので面積も0になります。密度は $${f(0.2)=2}$$ ですが、これは確率ではありません。<br />(4) $${E[X] = (0+0.5)/2 = 0.25}$$。分散は $${(0.5)^{2}/12 = 0.0208}$$ です。</p>

<p>問2<br />(1) 標準化します。</p>

<p>$$<br />Z = \frac{75-60}{15} = 1, \qquad P(Z \geq 1) = 0.1587<br />$$</p>

<p>約16%。「平均+1標準偏差より上」が約16%というのは、68%ルールの裏返しです。中央68%の外側が32%、その半分になります。<br /><br />(2) 上位10%の境目は $${Z = 1.28}$$ です。</p>

<p>$$<br />X = 60 + 15 \times 1.28 = 79.2<br />$$</p>

<p>約79点。<br /><br />(3) 偏差値70は $${Z=2}$$ です。$${60 + 15 \times 2 = 90}$$ 点。<br />(4) 標準化してから50と10で置き直します。</p>

<p>$$<br />\text{偏差値} = 50 + 10 \times \frac{X - 60}{15}<br />$$</p>

<p>問3<br />(1) 1時間に6件なので、1分あたり $${\lambda = 0.1}$$ 件です。</p>

<p>$$<br />X \sim \mathrm{Exp}(0.1), \qquad E[X] = \frac{1}{0.1} = 10\ \text{分}, \qquad V[X] = \frac{1}{0.1^{2}} = 100<br />$$</p>

<p>標準偏差も10分。平均10分に対してばらつきも10分で、かなり振れます。<br /><br />(2) $${P(X \gt 10) = e^{-0.1 \times 10} = e^{-1} \approx 0.368}$$。<br />(3) 無記憶性から、(2)とまったく同じ $${0.368}$$ です。10分待ったことは、この先に影響しません。<br />(4) 10分間の件数を $${N}$$ とすると $${N \sim \mathrm{Po}(1)}$$ です。</p>

<p>$$<br />P(N = 0) = \frac{1^{0} e^{-1}}{0!} = e^{-1} \approx 0.368<br />$$</p>

<p>一致しました。「10分間0件」と「待ち時間が10分を超える」は、同じ出来事を数と時間の両方から言っただけになります。</p>

<p>問4<br />(1) $${E[X] = 3 \times 2 = 6}$$、$${V[X] = 3 \times 2^{2} = 12}$$。<br />(2) 1件あたりの平均待ち時間が10分なので、尺度母数は $${b = 10}$$ です。</p>

<p>$$<br />X \sim \mathrm{Ga}(3, 10), \qquad E[X] = 3 \times 10 = 30\ \text{分}<br />$$</p>

<p>1件10分を3回ぶん。指数分布を3つ足しただけなので、期待値も3倍になります。<br /><br />(3) 期待値は $${3/(3+7) = 0.3}$$、最頻値は $${(3-1)/(3+7-2) = 0.25}$$。右に裾が伸びるぶん、平均が最頻値より大きくなっています。<br />(4) 期待値は $${3/(3+9) = 0.25}$$。単純な $${2/10 = 0.20}$$ より大きい値です。</p>

<p>事前分布 $${\mathrm{Be}(1,1)}$$ が「成功1回・失敗1回ぶんの、架空の観測」として効いています。データが10件しかないので、その1件ずつが無視できません。<br />データが増えれば、この差は消えていきます。第31章のベイズ法で正面から扱われます。</p>

<p>問5<br />(1) 中央値は $${e^{0} = 1}$$、期待値は $${e^{0 + 1/2} \approx 1.65}$$。期待値のほうが大きくなります。<br />(2) 中央値は $${e^{\log 400} = 400}$$ 万円です。期待値は</p>

<p>$$<br />E[X] = e^{\log 400 + 0.5^{2}/2} = 400 \times e^{0.125} \approx 400 \times 1.133 = 453\ \text{万円}<br />$$</p>

<p>中央値400万円に対して、平均は453万円。上のほうに伸びた裾が平均を引き上げています。<br /><br />(3) 絶対値の期待値が発散します。</p>

<p>$$<br />\int_{0}^{\infty} \frac{x}{\pi(1+x^{2})}\,dx = \frac{1}{2\pi} \Bigl[ \log(1+x^{2}) \Bigr]_{0}^{\infty} = \infty<br />$$</p>

<p>プラス側とマイナス側が両方とも発散するので、引き算が定まりません。左右対称だから0、という理屈は使えないことになります。</p>

<h2>⑥ 応用例</h2>

<p>実生活から2つ。</p>

<p>1つめ、バスの待ち時間です。<br />時刻表どおりに10分間隔で来るバスなら、待ち時間は $${U(0, 10)}$$ に近くなります。平均5分で、10分以上待つことはありません。<br />ところがタクシーが通りかかるのを待つ場合は違います。前のタクシーがいつ通ったかと、次がいつ来るかが無関係だからです。指数分布になります。</p>

<p>平均10分の指数分布で、20分以上待つ確率は $${e^{-2} \approx 0.135}$$。7回に1回は20分を超えます。<br />同じ「平均10分」でも、一様分布なら絶対に起きないことが、指数分布では普通に起きる。平均だけを見て予定を組むと、ここで外れます。</p>

<p>2つめ、年収です。<br />年収の分布は右に長い裾を持ち、対数正規分布でよく近似されます。練習問題5の数字がそのままの例です。中央値400万円に対して、平均は453万円。<br /><br />「平均年収」がぴんと来ないのは、この差のせいになります。裾のほうにいる少数が平均を持ち上げていて、真ん中にいる人の実感は中央値のほうに近い。<br />右に裾が伸びる量を見たら中央値を見る、という判断が、対数正規分布の実用そのものです。</p>

<p>医療の例に移ります。</p>

<p>1つめ、検査の基準範囲です。<br />健康診断の結果に付いてくる基準範囲は、一定の基準を満たす健常者の測定値の、<a href="https://www.jslm.org/books/guideline/2024/GL2024_04.pdf">中央95%の区間として設定されています</a>（日本臨床検査医学会「臨床検査のガイドライン」）。測定値が正規分布に近ければ $${\mu \pm 1.96\sigma}$$ です。</p>

<p>ここから、あまり気持ちのよくない帰結が出ます。健康な人のうち5%は、定義上どこかで基準範囲を外れます。<br />項目が独立だと粗く仮定すると、20項目測ったときに1つ以上外れる確率は</p>

<p>$$<br />1 - 0.95^{20} \approx 0.64<br />$$</p>

<p>約64%。まったく健康でも、20項目測れば3人に2人は「どこかに赤い印」が付く計算になります。<br />実際の検査項目は互いに相関しているので、この64%はそのままの数字ではありません。それでも、桁の見当としては働きます。基準範囲は正常と異常を分ける線ではない、と繰り返し言われる理由がここにあります。</p>

<p>2つめ、感染症の潜伏期間です。<br />潜伏期間の分布は、右に裾を引いた形になることが知られています。Sartwell が1950年に、多くの感染症で潜伏期間が対数正規分布によく当てはまることを示しました（Am J Hyg. 1950;51(3):310-318）。<br /><br />潜伏期間が対数正規に近いなら、平均より中央値を見るほうが実態に合います。「平均5日」と言われたときの5日は、たいてい真ん中より遅い側にある。<br />検疫期間を決めるときに使われるのは、平均ではなく上側のパーセント点です。分布の裾のどこで切るか、という話になります。</p>

<p>3つめ、生存時間解析です。<br />生存時間 $${T}$$ が指数分布に従うとき、ハザード関数は定数になります。</p>

<p>$$<br />h(t) = \frac{f(t)}{S(t)} = \frac{\lambda e^{-\lambda t}}{e^{-\lambda t}} = \lambda<br />$$</p>

<p>$${S(t) = P(T \gt t)}$$ が生存関数、$${h(t)}$$ が「そこまで生きた人が、次の瞬間に脱落する率」です。<br />これが $${t}$$ によらず一定というのは、無記憶性の言い換えになります。時間が経ってもリスクが変わらない、という強い仮定です。<br /><br />現実にはリスクが上がったり下がったりします。そこでガンマ分布やワイブル分布のように、形状母数でハザードの形を変えられる分布が使われる。第19章「回帰分析その他」の生存時間解析は、ここから始まります。</p>

<h2>⑦ 私がここで詰まった話</h2>

<p>第6章は、3ヶ月の独学でいちばん時間を使った章です。前編だけで6日止まりました。</p>

<p>最初に転んだのが、冒頭の2でした。</p>

<p>$${U(0, 0.5)}$$ の密度を計算して、2という数字が出た。確率が2。ありえません。<br />$${1/(b-a)}$$ の公式を間違えたのだと思って、$${b-a}$$ を分子に置いたり、$${1/2}$$ を掛けたりして、1以下になる組み合わせを探しました。1時間近く探しました。<br /><br />見つからないはずです。密度は1を超えてよいからです。</p>

<p>離散型を1章ぶん先にやったのが、裏目に出ていました。<br />第5章では $${f(x)}$$ が確率そのものでした。$${f(3) = 0.2}$$ なら確率0.2。頭がその読み方で固まっていて、$${f}$$ という記号を見ると反射的に確率だと思っていました。<br /><br />抜けたのは、単位を書いてみたときです。</p>

<p>密度の単位は「1あたり」です。長さの分布なら1cmあたり、時間の分布なら1分あたり。<br />$${f(x) = 2}$$ は「このあたりでは1単位あたり2」であって、確率ではありません。幅0.5を掛けて、はじめて1になる。<br />人口密度が5000人/km²でも人口が5000人ではないのと、まったく同じでした。</p>

<p>ノートに1行書きました。「$${f(x)}$$ は高さ。確率は面積」。</p>

<p>もう1か所、ガンマ分布でも止まりました。<br />練習問題の答えが合わず、$${E[X]}$$ が本と逆数の関係になっていました。$${ab}$$ のはずが $${a/b}$$ になる。<br /><br />原因は流儀でした。ワークブックは $${e^{-x/b}}$$ と書いて $${b}$$ を尺度母数にしています。私が見ていたサイトは $${e^{-bx}}$$ で、$${b}$$ は率でした。同じ $${b}$$ という文字で、意味が逆数になっている。<br /><br />第5章の負の二項分布とまったく同じ転び方です。あのときは「数えている対象が違う」で、今回は「$${b}$$ の意味が違う」。式は正しいのに、記号の中身が違っていました。</p>

<p>2回同じ転び方をしたので、確認のしかたを決めました。<br />新しい分布を見たら、まず期待値の式を1つだけ覚える。$${E[X] = ab}$$ か $${a/b}$$ か。あとは数値をひとつ入れて、それに合う流儀かどうかを確かめる。<br />密度の式を見比べるより、これが速い。</p>

<p>そしてこの章の本当の山は、まだ来ていません。カイ二乗・$${t}$$・$${F}$$ です。<br />前編の7つは、どれも「何を待つか」「何の割合か」という日本語の説明が付きました。後編の3つには、それがありません。</p>

<h2>⑧ 次回</h2>

<p>第6章の後編です。記号は $${\chi^{2}}$$。<br /><br />2変量正規分布と混合正規分布を片づけてから、カイ二乗分布、$${t}$$ 分布、$${F}$$ 分布に入ります。<br />標準正規分布を2乗して足すとカイ二乗分布になる。そこで使うのが、第4章の変数変換です。<br /><br />前編の分布が「現象そのものの分布」だったのに対して、後編は「標本から計算した値の分布」になります。見ている場所が変わります。</p>
